# Smart App Usage Controller

## Project Description
This Android application is designed to improve productivity and time management by controlling app usage. Users can select apps, set time limits, and the app will block usage once the limit is reached. After a cooldown period, the apps are unlocked for use again.  

## Features
- Select apps to track
- Set time limits for each app
- Real-time usage tracking
- Auto block apps when time limit is reached
- Cool-down timer for blocked apps
- Daily usage summary report (optional)
- Simple and clean user interface

## Technology Stack
- Kotlin (Android Development)
- Android Studio
- Background Services & Usage Stats
- Accessibility / Overlay Permissions

## How it Works
1. User selects apps and sets time limits
2. App tracks usage in the background
3. Once time is over, app shows a lock screen and prevents further use
4. After cooldown, apps are unlocked automatically
